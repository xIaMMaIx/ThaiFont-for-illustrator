# Thai Font Studio 2.0 (Adobe Illustrator panel)

ปลั๊กอินสำหรับออกแบบฟอนต์ไทยและอังกฤษใน Illustrator: วาดทีละตัวบน Canvas เดียว จัดช่องไฟและตำแหน่งสระ/วรรณยุกต์แบบเห็นภาพ แล้วส่งออกเป็นไฟล์ OpenType (.otf) ที่จัดรูปภาษาไทยถูกต้อง

ต้องใช้ Illustrator CC 2019 (v23) ขึ้นไป

---

## ติดตั้ง

**ปิด Illustrator ก่อน** แล้วดับเบิลคลิกตัวติดตั้งในโฟลเดอร์นี้ (หรือในโฟลเดอร์ที่แตกจาก zip)

| | Windows | macOS |
|---|---|---|
| ติดตั้ง / อัปเดต | `install-windows.bat` | `install-mac.command` |
| ถอนการติดตั้ง | `uninstall-windows.bat` | `uninstall-mac.command` |

จากนั้นเปิด Illustrator → **Window › Extensions › Thai Font Studio**

ตัวติดตั้งทำให้ครบในขั้นเดียว:
- ตรวจว่า Illustrator ปิดอยู่ (ไฟล์ที่เปิดอยู่ทับไม่ได้ และ Illustrator จำ panel เดิมไว้)
- ลบเวอร์ชันเก่าแล้ว **คัดลอกเฉพาะไฟล์ที่ panel ใช้** (`CSXS src libs icons index.html styles.css hostScript.jsx`) ไปที่
  - Windows: `%APPDATA%\Adobe\CEP\extensions\IllusFont`
  - macOS: `~/Library/Application Support/Adobe/CEP/extensions/IllusFont`
- ตรวจว่าคัดลอกครบ, เปิด `PlayerDebugMode` (CSXS 9–13 = Illustrator 2019 ถึงรุ่นล่าสุด) ให้รันส่วนขยายที่ยังไม่เซ็นชื่อได้
- macOS: ลบ quarantine ที่ติดมากับไฟล์ zip ที่ดาวน์โหลด (ไม่ลบ Illustrator จะไม่แสดง panel โดยไม่แจ้งอะไร)
- เตือนถ้ามีอีกชุดใน `Common Files\Adobe\CEP\extensions` (สองชุด = Illustrator อาจโหลดเวอร์ชันเก่า)

ตัวเลือก (พิมพ์ใน Command Prompt / Terminal):
- `install-windows.bat debug` / `./install-mac.command debug` — เปิด remote debugging: ขณะเปิด panel ให้เข้า `http://localhost:8088` ใน Chrome เพื่อดู Console
- `install-windows.bat link` / `./install-mac.command link` — **สำหรับพัฒนา**: ลิงก์ (junction/symlink) โฟลเดอร์ส่วนขยายมาที่โฟลเดอร์นี้ แก้โค้ดแล้วกดปุ่มโหลดใหม่บน panel ได้เลย ไม่ต้องติดตั้งซ้ำ
  ถ้าติดตั้งแบบปกติทับลิงก์ ตัวติดตั้งจะลบเฉพาะตัวลิงก์ ไม่แตะโฟลเดอร์ปลายทาง

หลังอัปเดต panel จะโหลด `hostScript.jsx` รุ่นใหม่ให้เอง (เทียบค่า build) ไม่ต้องปิด Illustrator ถ้าใช้แบบลิงก์

### แก้ปัญหา
- **ไม่มีเมนู Thai Font Studio** — ปิด Illustrator ให้สนิท (รวม background process) แล้วเปิดใหม่ · ตรวจว่า Illustrator เป็น 2019 (v23) ขึ้นไป · รันตัวติดตั้งซ้ำ (เปิด PlayerDebugMode ให้อีกครั้ง)
- **panel ว่างเปล่า / ค้าง** — ติดตั้งแบบ `debug` แล้วดูข้อผิดพลาดที่ `http://localhost:8088`
- **แถบแดง "ไฟล์ใน panel ไม่ตรงเวอร์ชัน"** — ไฟล์ปนกันหลายรุ่น ปิด Illustrator แล้วรันตัวติดตั้งใหม่
- **macOS: เปิด .command ไม่ได้** — คลิกขวา › Open หรือรัน `bash install-mac.command` ใน Terminal

## การใช้งาน

### แท็บ วาด
- กด **สร้างเอกสารฟอนต์ใหม่** (800×800 pt พร้อมเส้นไกด์) หรือ **ใช้เอกสารนี้** กับไฟล์ที่เปิดอยู่
- คลิกตัวอักษรในตาราง ปลั๊กอินจะซ่อน Layer อื่นแล้วเปิด Layer ของตัวนั้นให้วาดทันที (`glyph_U+0E01` ฯลฯ)
- กด `[` และ `]` เพื่อเลื่อนไปตัวก่อนหน้า/ถัดไป
- จุดสีบนช่อง: เขียว = วาดแล้ว · ฟ้า = สร้างอัตโนมัติ (ำ, ญ/ฐ ตัดเชิง) · ส้ม = มีจุดที่ควรแก้
- ใต้ตัวที่เลือกจะมีคำแนะนำ เช่น "มีเส้น Stroke — จะแปลงเป็นรูปทรงตอนส่งออก" พร้อมปุ่มแก้ให้ทันที
- วาดด้วย Stroke, Brush, ข้อความ หรือ Symbol ได้ ตอนส่งออกระบบจะ Expand/Outline Stroke บนสำเนาชั่วคราวให้ ต้นฉบับไม่เปลี่ยน
- รูเจาะ (เช่น อ, O) ให้ใช้ Compound Path (Ctrl+8) รูปสีขาวที่วางทับจะถูกตีความเป็นรูเจาะ แต่จะมีคำเตือน

### แท็บ ใส่เส้น
ใส่ลายมือที่ trace มาลงช่องตัวอักษรทีละตัว โดยไม่ต้อง copy/paste และสลับ Layer เอง
1. Image Trace (ติ๊ก Ignore White) → Expand → Ungroup แล้ววางไว้นอก Artboard ใน Layer "Reference" ของเอกสารฟอนต์
2. เลือกเส้นของตัวหนึ่งบน Canvas แล้วคลิกช่องตัวอักษรในแท็บนี้ ระบบจะคัดลอกไป Layer ของตัวนั้น วางบนเส้นฐาน/กึ่งกลางไกด์ ทำต้นฉบับให้จาง แล้วไปตัวถัดไปที่ยังไม่วาด
- **ขนาดเท่ากันทุกตัว**: ตัวแรกที่ใส่ (ควรเป็น ก น หรือ H) ใช้ตั้งอัตราย่อขยาย ทุกตัวหลังจากนั้นใช้อัตราเดียวกัน สัดส่วนลายมือจึงคงเดิม · **ขนาดเดิม**: ไม่ย่อขยาย
- ตัวที่วาดแล้วจะถามก่อนแทนที่ · ภาพสแกนที่ติดมาในที่เลือกจะถูกข้าม
- เข้าแท็บนี้ครั้งแรกแล้ว Layer อ้างอิงยังว่าง จะมีกล่องแจ้งเตือนให้วางเส้นก่อน (นอก Artboard) และแถบเตือนค้างไว้จนกว่าจะมีเส้น ปุ่ม "เตรียม Layer Reference ให้วาง" จะสร้าง/ปลดล็อก Layer แล้วตั้งเป็น Layer ที่ใช้งาน ให้ Ctrl+V วางลงที่นั่น · ถ้ามีเส้นอ้างอิงทับ Artboard หรือ Layer ถูกล็อก/ซ่อน ก็จะเตือนเช่นกัน
- **ใส่ผิดตัว**: ชี้ที่ช่องแล้วกด × เพื่อลบตัวนั้น หรือกด **เลือกลบหลายตัว** แล้วคลิกช่องที่จะลบ (มี "เลือกทั้งหมด") → **ลบที่เลือก** · ถามยืนยันก่อนเสมอ ระบบลบ Layer ของตัวนั้นทิ้งทั้ง Layer (ใส่ใหม่เมื่อไรจะสร้าง Layer ให้เอง) และต้นฉบับบน Canvas จะกลับมาเข้มเหมือนเดิม

### แท็บ ช่องไฟ
- **ความแน่นของตัวอักษร**: ชิดมาก → โปร่งมาก ใช้กับทุกตัว
- **ช่องไฟพื้นฐาน** (pt): ระยะของตัวที่ขอบตรง เช่น น, H
- **ผลของขอบโค้ง**: ตัวที่ขอบโค้งหรือเฉียง (อ, O, A) จะได้ช่องไฟน้อยลงตามค่านี้ เพื่อให้ดูห่างเท่ากัน
- **ปรับทีละตัว**: ดูตัวที่เลือกวางระหว่าง น_น / H_H / n_n แล้วลากขอบสีอำพัน (ซ้าย) หรือขอบสีเขียวฟ้า (ขวา) ได้เลย หรือกด − / + (Shift = ทีละ 10)
  ตัวเลขแสดงเป็น "อัตโนมัติ + ปรับ" จึงเห็นเสมอว่าเปลี่ยนจากค่าที่ระบบคำนวณไปเท่าไร
- **Kerning**: พิมพ์คู่ตัวอักษร เช่น `AV` แล้วปรับระยะ หรือเปิด Kerning อัตโนมัติ (เลือกได้ว่าใช้กับอังกฤษ/ตัวเลข หรือทุกตัว)

สีบนแผงตรงกับเส้นไกด์บน Canvas: ซ้าย = อำพัน, ขวา = เขียวฟ้า, หัวตัว (Cap) = ฟ้า, เส้นฐาน = เขียว

### แท็บ สระ/วรรณยุกต์
- ข้อความตัวอย่างด้านบนใช้ **ฟอนต์จริงที่กำลังทำ** (คอมไพล์ใหม่ทุกครั้งที่แก้)
- ระยะ A–F: สระบนห่างหัวพยัญชนะ, วรรณยุกต์ซ้อนห่างสระบน, สระล่างห่างเส้นฐาน, ระยะหลบหางสูง และเลื่อนซ้าย/ขวา
- วรรณยุกต์แต่ละตัวเลื่อนซ้าย/ขวาแยกกันได้
- **วรรณยุกต์ที่ซ้อนบนสระบน** (กิ่ ปี้ ซึ้ง ปั้) เลื่อนแยกจากตอนไม่ซ้อนได้ 3 ชั้น บวกกันเป็นตำแหน่งสุดท้าย (+ = ไปทางขวา):
  - **G** เลื่อนวรรณยุกต์ซ้อนทุกตัว
  - รายวรรณยุกต์ (◌ิ่ ◌ิ้ …) เฉพาะตอนซ้อน
  - รายสระบน: เลือกสระบน (ิ ี ึ ื ั ็ ํ) แล้วปรับ "วรรณยุกต์ซ้อน ←→ / ↑↓" ในกรอบปรับเฉพาะตัว
- **ปรับเฉพาะตัว**: เลือกพยัญชนะเพื่อขยับจุดวางสระบน/ล่างของตัวนั้น หรือเลือกสระ/วรรณยุกต์เพื่อเลื่อนตัวมันเอง

กติกาอัตโนมัติ: สระบนและวรรณยุกต์ชิดขอบขวาของหลักขวา, ตัวที่หางสูงเกินเส้นส้ม (ป ฝ ฟ ฬ รวมถึง ส ศ ที่หางสูง) จะหลบไปทางซ้าย ยกเว้นเครื่องหมายที่ตั้งเป็น "ทะลุหางสูงได้" (ค่าเริ่มต้นคือ ั) ซึ่งจะวางตำแหน่งปกติให้หางทับหลักได้ ส่วนวรรณยุกต์ที่ซ้อนบน ั ยังหลบซ้ายให้ (ปั่ ฝั้), ฎ ฏ ที่มีเชิงล่างสระล่างจะเลื่อนลงให้, ญ ฐ + สระล่างจะสลับเป็นตัวตัดเชิง

### แท็บ จูนอัตโนมัติ
ให้ระบบคำนวณช่องไฟและตำแหน่งสระ/วรรณยุกต์จากเส้นที่วาดจริง เป็นจุดเริ่มต้นที่สม่ำเสมอ แล้วคุณปรับละเอียดต่อในแท็บ ช่องไฟ / สระ/วรรณยุกต์

ขั้นตอน: **วิเคราะห์ → ดูก่อน/หลัง → ใช้ทั้งหมด → ปรับละเอียด** (ยังไม่แก้ค่าจริงจนกว่าจะกด "ใช้ทั้งหมด" และกด "ย้อนกลับ" ได้)

- **ช่องไฟ**: ช่องไฟ = ช่องไฟพื้นฐาน − ความลึกของขอบเว้า (จำกัดความลึก) ± ค่าตามกลุ่มรูปทรง (ขอบตรง / โค้งเล็กน้อย / เว้าลึก) ผลออกมาเป็น "ค่าปรับ" ต่อตัว จึงเห็นเสมอว่าเปลี่ยนจากอัตโนมัติเดิมไปเท่าไร
- **ระยะรวม A–D**: คำนวณจากความหนาเส้นของตัวอักษร (ฟอนต์หนาได้ระยะห่างมากกว่าฟอนต์บาง) และปรับ B ให้วรรณยุกต์ซ้อนสระห่างเท่ากับระยะเป้าหมายจริง
- **ตำแหน่งสระ/วรรณยุกต์รายตัว**: จำลองการวางแบบเดียวกับ GPOS แล้ววัดระยะสั้นสุดจากขอบสระถึงขอบหมึกพยัญชนะ ยกขึ้นถ้าชิดเกิน ลดลงบางส่วนถ้าห่างเกิน (ตัวเลือก "ตามรูปทรงหัวตัว") ขยับซ้ายถ้าเท้า/หางยื่นขวากว่าหลักที่หัวตัว และหลบหางสูงตามระยะ D
- **ตารางตรวจ**: พยัญชนะทุกตัว สีเขียว = ผ่าน, เหลือง = ชิดเกินไป, ชน = แดง กดตัวไหนก็ดูระยะของทุกสระ/วรรณยุกต์ (รวมวรรณยุกต์ซ้อนสระ) และปรับเฉพาะตัวได้ทันที
- **ค่าที่คุณปรับเอง = ล็อก**: ระบบจำค่าที่ตัวเองใส่ไว้ ตัวที่ค่าไม่ตรงกับที่ระบบใส่ (คุณแก้เอง) จะถูกข้าม เว้นแต่ติ๊ก "เขียนทับค่าที่ฉันปรับเองด้วย" ในตั้งค่าขั้นสูง
- **สไตล์** ชิด / ปกติ / โปร่ง ตั้งค่าขั้นสูงให้ครั้งเดียว ปรับละเอียดได้ในตั้งค่าขั้นสูง

ข้อจำกัด: ระยะ B (วรรณยุกต์ห่างสระ) เป็นค่ารวมของทุกตัว ตารางตรวจจึงแก้ตัวที่ชนจากค่า B ไม่ได้ถ้าปิด "ระยะรวม A–D"

### Kerning ภาษาอังกฤษ (คำนวณจากตัวอักษรในโปรเจกต์)

เปิดที่ แท็บ ช่องไฟ → Kerning อัตโนมัติ — สูตรไม่อิงฟอนต์ใด วัดทุกค่าจากตัวที่วาดจริง (`src/latin-kern.js`):

- **S** ความหนาเส้น = ความกว้างหลักที่แคบสุดของ n l i H I · **XH** x-height = มัธยฐานความสูงตัวพิมพ์เล็ก
- **Aref** ช่องไฟปกติ = พื้นที่ว่างเฉลี่ยระหว่าง n–n (ตัวเล็ก) และ H–H (ตัวใหญ่/ตัวเลข) ตามช่องไฟที่ตั้งไว้เอง
- คู่ L→R: เลื่อน R จนพื้นที่ว่างเฉลี่ย (ตามแถวที่ R มีหมึก) เท่า Aref · แถวที่ L ไม่มีหมึก (ใต้แขน T) นับเป็นช่องเปิดได้ไม่เกิน `Aref + ลึกสุด·S`
  ตัวเตี้ยจึงเข้าใต้แขน T ได้ ส่วนตัวหางสูง (b d f h k l) ก้านชนแขนก่อนจึง kern น้อย/ไม่ kern เอง ไม่ต้องมีรายชื่อยกเว้น
- กันชนด้วยระยะ 2 มิติจริง (รวมระยะแนวตั้งใต้แขน และเซริฟ) · จัดค่าเป็นกลุ่ม (สูงเท่ากัน + ขอบซ้ายตรง/โค้ง) ให้จังหวะสม่ำเสมอ
- ปรับได้: ชิดใต้แขน (ค่าเริ่ม 0.65), ลึกสุด (1.0), ความแรง · ค่าที่พิมพ์เองในรายการคู่ใช้แทนเสมอ
- พรีวิวมีชุดข้อความ "Kerning ทดสอบ" (To Ta Te…, AV VA…, rn vv…)
- เทียบกับ kerning ของนักออกแบบ 6 ฟอนต์: ฟอนต์ไม่มีเชิงใกล้เคียง (ขนาดรวม ≈ ±10%, คลาดเฉลี่ย ≈ 3% ของความสูงตัวใหญ่) ฟอนต์มีเชิงยัง kern น้อยกว่านักออกแบบ

### ปรับเฉพาะตัว: แนวตั้ง และหาง (แท็บ ช่องไฟ)
สำหรับตัวที่ต้องปรับ baseline ทีละตัว เช่น อักษรวิจิตรที่หางล้นลงใต้เส้นฐาน:
- **แนวตั้ง (pt, + = ขึ้น)**: เลื่อนทั้งตัวตอนคอมไพล์ โดยไม่ต้องกลับไปขยับงานใน Illustrator ลากตัวอักษรในเวทีขึ้น/ลงได้ (Shift = ทีละ 10) ช่องไฟอัตโนมัติวัดใหม่จากรูปที่ยกแล้ว
- **ไม่นับหางใต้เส้นฐาน**: ช่องไฟอัตโนมัติและ Kerning ของ Latin คิดจากหมึกเหนือเส้นฐานเท่านั้น หางจึงยื่นไปอยู่ใต้ตัวถัดไปได้ · **เปิดเป็นค่าเริ่มต้น** ในอักษรหางยาว (ฎ ฏ ฤ ฦ) และตัวเชิง (ญ ฐ) ตัวอื่นเช่น g y p ปิดไว้ ติ๊กเปลี่ยนต่อตัวได้ (ระบบจำเฉพาะตัวที่ต่างจากค่าเริ่มต้น)
- เวทีและภาพย่อแสดงเส้นฐาน (เขียว) และ Descender (ม่วง) ภาพย่อในตารางขยายให้เห็นหางลึกสุดทั้งโปรเจกต์
- ตอนส่งออก ถ้ามีตัวที่หมึกต่ำกว่าเส้น Descender จะมีคำเตือนบอกว่าตัวไหนและระยะบรรทัดอัตโนมัติถ่างขึ้นเท่าไร (ตั้ง Metrics เป็น Manual ถ้าไม่ต้องการให้ถ่าง)
- เก็บในไฟล์ตั้งค่าที่ `glyphAdjust: { "U+0067": { dy, tail } }`

### เส้นฐานเฉพาะตัว และลูกเล่นเส้นฐาน (แท็บ ช่องไฟ)
สำหรับฟอนต์ที่ตั้งใจให้ตัวอักษรสูงต่ำไม่เท่ากัน
- **เส้นฐานเฉพาะตัว (pt, + = ขึ้น)**: ยกทั้งตัวตอนคอมไพล์ ต่างจากช่อง "แนวตั้ง" ตรงที่ช่องไฟ Kerning และจุดยึดยังวัดจากรูปเดิม ความกว้างจึงไม่เปลี่ยน และสระ/วรรณยุกต์ย้ายตามตัวฐาน · ญ ฐ ตัดเชิงใช้ค่าเดียวกับตัวเต็ม
- **ลูกเล่นเส้นฐาน**: เลือกกลุ่ม (พยัญชนะไทย / อังกฤษ / ทั้งคู่) แบบ (สูง/ต่ำ, สูง/กลาง/ต่ำ, อิสระ) และความสูงต่าง แล้วกด **สุ่มความสูง** · กดซ้ำเพื่อสุ่มใหม่ จะเขียนทับค่าของตัวในกลุ่มนั้น กด "ย้อนกลับ" เพื่อเอาค่าก่อนหน้าคืน แล้วปรับต่อทีละตัวได้
- สองอย่างนี้ผูกกับตัวอักษร ตัวเดียวกันจึงสูงเท่ากันทุกครั้งที่พิมพ์ ถ้าต้องการให้ตัวซ้ำต่างกันใช้รูปสลับด้านล่าง
- **รูปสลับในข้อความ**: เลือกกลุ่ม จำนวนจังหวะ (2: ปกติ → ขึ้น, 3: ปกติ → ขึ้น → ลง) และความสูงต่าง ระบบจะสร้าง glyph เพิ่มที่ยกเส้นฐานต่างกัน แล้วใช้ `calt` หมุนเวียนตามลำดับที่พิมพ์ เช่น "นนนน" จะเด้งไล่กัน
    - ความกว้าง Kerning และจุดยึดเหมือนรูปปกติ สระ/วรรณยุกต์ย้ายตาม ญ ฐ ตัดเชิงมีรูปสลับด้วย และบวกเพิ่มจากเส้นฐานเฉพาะตัวของตัวนั้น
    - นับข้ามสระบน/ล่าง วรรณยุกต์ และสระหน้า/หลังได้ไม่เกิน 2 ตัวติดกัน · เว้นวรรคหรือตัวนอกกลุ่มจะเริ่มรอบใหม่ที่รูปปกติ
    - โปรแกรมที่ไม่รองรับหรือปิด Contextual Alternates จะแสดงรูปปกติ
- ความสูงบรรทัดอัตโนมัติขยายตามตัวที่ยกหรือกดลง · เก็บในไฟล์ตั้งค่าที่ `glyphBaseline: { "U+0E01": 30 }` และ `baselineAlt: { on, scope, steps, amount }`

### แท็บ ส่งออก
- ใส่ชื่อฟอนต์และสไตล์ (น้ำหนัก Bold/Light ฯลฯ จะถูกตั้งค่าในฟอนต์ให้ตรง)
- **ความสูงบรรทัดอัตโนมัติ** คำนวณจากตัวที่สูง/ต่ำที่สุด รวมสระและวรรณยุกต์ที่ซ้อนสูงสุด ไม่มีหัวหรือหางขาดบน Windows
- ไม่แนะนำให้ "ใส่กล่องแทนตัวที่ยังไม่วาด" เพราะโปรแกรมจะแสดงกล่องแทนการใช้ฟอนต์อื่นช่วย
- **นำเข้าจากฟอนต์ที่มีอยู่** (.otf/.ttf/.woff): สร้าง Layer ให้ทุกตัว ย่อ/ขยายให้พอดีเส้น Cap และนำช่องไฟ + Kerning เดิมมาเป็นค่าปรับได้

ค่าตั้งค่าทั้งหมดถูกบันทึกในไฟล์ .ai (Layer `_TFS Data` ที่ซ่อนไว้) พร้อมสำรองในเครื่อง

## สิ่งที่อยู่ในไฟล์ .otf

| ส่วน | ทำอะไร |
|---|---|
| `GPOS mark` | วางสระบน/ล่าง/วรรณยุกต์ตามจุดยึดของพยัญชนะแต่ละตัว |
| `GPOS mkmk` | วรรณยุกต์ซ้อนบนสระบน (ปี่ กิ้ น้ำ) |
| `GPOS kern` | ระยะคู่ตัวอักษร (ข้ามสระ/วรรณยุกต์ได้) |
| `GSUB ccmp` | ำ → ํ + า, ญ/ฐ + สระล่าง → ตัดเชิง |
| `GSUB calt` | หมุนเวียนรูปสลับความสูง (เฉพาะเมื่อเปิด "รูปสลับในข้อความ") |
| `GDEF` | บอกว่าตัวไหนเป็นสระ/วรรณยุกต์ |
| อื่น ๆ | ◌ (U+25CC), เว้นวรรค + NBSP, ZWSP/ZWJ/ZWNJ, ค่าน้ำหนักและความสูงบรรทัดใน OS/2/hhea |

สระและวรรณยุกต์ยังถูกวางตำแหน่งสำรองไว้ในตัว glyph ด้วย (กว้าง 0, ถอยมาทางซ้าย) โปรแกรมเก่าที่ไม่รองรับ GPOS จึงยังแสดงผลพอใช้ได้

## พัฒนา

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install          # ติดตั้งครั้งแรก
npm run dev          # เปิด panel ในเบราว์เซอร์ (โหมดจำลอง ไม่ต้องเปิด Illustrator) → http://localhost:5178
npm run stamp        # รันทุกครั้งหลังแก้ไฟล์ใน src/ หรือ hostScript.jsx
```

`npm run stamp` เขียนค่า build (เลขเวอร์ชัน + hash ของเนื้อหา) ลงท้ายไฟล์ใน `src/` และ `hostScript.jsx`
panel ใช้ค่านี้ตรวจว่าไฟล์ที่ติดตั้งเป็นชุดเดียวกัน และโหลด `hostScript.jsx` ใหม่เองเมื่อไม่ตรง
เลขเวอร์ชันแก้ที่ `package.json` ที่เดียว แล้ว stamp จะอัปเดต `manifest.xml` และ `hostScript.jsx` ให้

### สร้างไฟล์สำหรับแจกจ่าย

```bash
npm run package
```

ได้ไฟล์ `dist/ThaiFontStudio-<version>.zip` (ตัวติดตั้ง + README + โฟลเดอร์ส่วนขยาย) ผู้ใช้แตก zip แล้วดับเบิลคลิกตัวติดตั้งได้เลย

ถ้าต้องการไฟล์ `.zxp` ที่เซ็นชื่อแล้ว (ติดตั้งผ่าน ExManCmd หรือ Anastasiy's Extension Manager ได้โดยไม่ต้องเปิด PlayerDebugMode)
ให้ตั้งค่า `ZXP_CERT=cert.p12` และ `ZXP_PASS=...` ก่อนรัน · สร้างใบรับรองได้ด้วย `ZXPSignCmd -selfSignedCert ...` และกำหนดตำแหน่งโปรแกรมด้วย `ZXP_SIGN_CMD` ถ้าไม่อยู่ใน PATH

## อัปเกรดจากเวอร์ชัน 1

ไฟล์ .ai ที่ทำไว้กับเวอร์ชัน 1 เปิดใช้ต่อได้ทันที ชื่อ Layer ยังเหมือนเดิม และค่าที่ตั้งไว้ (ระยะสระ/วรรณยุกต์, ช่องไฟรายตัว, ข้อมูลฟอนต์) จะถูกแปลงเป็นรูปแบบใหม่ให้อัตโนมัติเมื่อเปิดครั้งแรก
